Общий вид запроса:

```
SELECT [DISTINCT] столбцы
FROM таблица
WHERE условие
GROUP BY столбцы
HAVING условие
ORDER BY столбцы;
```

- `SELECT` - выбор столбцов
- `FROM` - таблица-источник
- `WHERE` - условие отбора строк
- `GROUP BY` - группировка строк
- `HAVING` - условие отбора групп
- `ORDER BY` - сортировка результата
- `DISTINCT` - удаление повторов
- `*` - все столбцы

---

**Алиасы AS**

Переименование столбцов или таблиц.

```
SELECT LastName AS Family
FROM Persons;
```

**DISTINCT**

Выбор уникальных значений.

```
SELECT DISTINCT Company
FROM Orders;
```

---

**WHERE. Условия выборки**

```
SELECT *
FROM Persons
WHERE City = 'Sandnes';
```

|Оператор|Значение|
|---|---|
|`=`|Равно|
|`<>`|Не равно|
|`>`|Больше|
|`<`|Меньше|
|`>=`|Больше или равно|
|`<=`|Меньше или равно|
|`BETWEEN`|В заданном диапазоне|
|`LIKE`|Поиск по шаблону|

**BETWEEN**

Проверка попадания значения в диапазон.

```
SELECT *
FROM Persons
WHERE Year BETWEEN 1960 AND 1980;
```

В стандартном SQL границы включаются в диапазон.

**LIKE**

Поиск строк по шаблону.

```
SELECT *
FROM Persons
WHERE FirstName LIKE 'O%';
```

|Символ|Значение|
|---|---|
|`%`|Любое количество символов, включая ноль|
|`_`|Один любой символ|
|`[]`|Диапазон или набор символов в некоторых СУБД|
|`[^]`|Исключающий диапазон в некоторых СУБД|

Примеры:

```
LIKE 'O%'       -- начинается с O
LIKE '%a'       -- заканчивается на a
LIKE '%la%'     -- содержит la
LIKE '_a%'      -- второй символ a
```

Синтаксис `[]` и `[^]` зависит от СУБД. В PostgreSQL для таких шаблонов используют другие средства.

---

**ORDER BY. Сортировка**

- `ASC` - по возрастанию, используется по умолчанию.
- `DESC` - по убыванию.

```
SELECT *
FROM Persons
ORDER BY LastName ASC;
```

Сортировка по нескольким столбцам:

```
SELECT *
FROM Orders
ORDER BY Company ASC, OrderNumber DESC;
```

Сначала сортировка по компании, затем по номеру заказа внутри каждой компании.

---

**AND и OR**

- `AND` - должны выполняться все условия.
- `OR` - достаточно одного условия.

```
SELECT *
FROM Persons
WHERE FirstName = 'Tove'
AND LastName = 'Svendson';
```

```
SELECT *
FROM Persons
WHERE FirstName = 'Tove'
OR LastName = 'Svendson';
```

Скобки задают порядок выполнения условий.

---

**SELECT IN**

Выбор строк, значение которых входит в заданный список.

```
SELECT *
FROM Persons
WHERE LastName IN ('Hansen', 'Pettersen');
```

Эквивалентно нескольким условиям, объединённым через `OR`.

## Некоторые функции MS Access

| Функция          | Описание                                                |
| :--------------- | :------------------------------------------------------ |
| `AVG(column)`    | Возвращает среднее значение столбца                     |
| `COUNT(column)`  | Возвращает количество строк столбца (без значений NULL) |
| `COUNT(*)`       | Возвращает количество выбранных строк                   |
| `FIRST(column)`  | Возвращает значение первой записи в указанном поле      |
| `LAST(column)`   | Возвращает значение последней записи в указанном поле   |
| `MAX(column)`    | Возвращает наибольшее значение столбца                  |
| `MIN(column)`    | Возвращает наименьшее значение столбца                  |
| `STDEV(column)`  | Стандартное отклонение для выборки                      |
| `STDEVP(column)` | Стандартное отклонение для генеральной совокупности     |
| `SUM(column)`    | Возвращает общую сумму столбца                          |
| `VAR(column)`    | Статистическая дисперсия выборки                        |
| `VARP(column)`   | Дисперсия генеральной совокупности                      |
