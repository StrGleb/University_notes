#### Нужны тесты, то есть правильная обработка ситуаций

1. скобки после return не нужны
2. все названия на английском
3. названия переменных должны быть осмысленными
4. не использовать of, the в названиях
5. булевы переменные называть как вопрос, на которые можно ответить да/нет
6. названия переменных в lowerCamelCase
7. не оставлять пустых строк после объявления и return 
8. не надо лишних комментариев
9. тело if в новой строке всегда 
10. если в теле if больше 1 строки, использовать скобки
11. пишется одна и та же строчкуа - выделить в метод
12. не сравнивать bool с константой 
13. названия методов в UpperCamelCase
14. названия методов должны начинаться с глагола
15. использовать множественное чисто в названии коллекций (массив apples)
16. всегда явно указывать модификаторы доступа
17. внутри класса порядок: поля, свойства, конструктор, публичные методы и 
18. после методов пробел
19. после for, if пробелы
20. обрамлять + - / * = ==
21. правильно переносить тернарный оператор 
22. перенос так, чтобы строка начиналась с оператора
23. для записи однострочных свойств =>
24. при записи длинной цепочки методов вызовов писать каждый вывод в новой строке
25. типы переменных используются явно
